BREYLEE Skincare Indonesia — WordPress Theme

INSTALASI
1. Masuk ke Dashboard WordPress.
2. Buka Tampilan (Appearance) > Tema (Themes) > Tambah Tema Baru.
3. Klik Unggah Tema (Upload Theme), pilih breylee-skincare.zip.
4. Klik Instal Sekarang, lalu Aktifkan.

CATATAN
- Tema menggunakan Tailwind CSS CDN, Google Fonts, dan Font Awesome CDN; koneksi internet diperlukan untuk memuat aset tersebut.
- Konten utama mengikuti HTML sumber yang diberikan. Navigasi antarbagian bekerja sebagai tampilan satu halaman.
- Form kontak pada sumber hanya menampilkan simulasi notifikasi; belum terhubung ke email atau layanan formulir.
- Tombol keranjang merupakan demonstrasi dan checkout mengarah ke Shopee. Sesuaikan tautan toko, produk, harga, foto, dan materi promosi sebelum dipublikasikan.
- Untuk mengubah identitas situs, gunakan Pengaturan > Umum dan unggah logo melalui Identitas Situs bila diperlukan.
